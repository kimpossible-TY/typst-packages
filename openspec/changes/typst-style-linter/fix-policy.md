# Automatic repair catalog

This file is normative for `typst-lint-autofix`. Rule detection and grades remain in the two style specs. **Automatic** means apply without a per-finding prompt when the rule's preconditions and the protected write contract hold. **Conditional** means automatic only for the exact bounded case below. **Diagnostic only** means no source repair is determined by current policy, not that compilation may silently proceed. Every active, unresolved finding blocks the authoritative build gate; a reasoned suppression remains available.

Global invariants: resolve the named API to its actual helper, reject shadowing/unknown provenance, edit only the smallest syntax spans, preserve comments/directives and original literal data unless the row explicitly changes it. Reparse and rerun all enabled rules after each pass. A precondition failure produces `fix_unavailable` with a reason, never a guessed replacement. Interleaved comments, side effects, unknown arguments, or external consumers defeat any transformation that depends on their absence. Each row's eligible case needs exact before/after, ineligible, and second-run-zero-edit fixtures. The preserved data and intended effect below are assertions, not promises of identical rendering.

## Required combined and rendered fixtures

- Marker insertion before `this consequence follows.` preserves its lowercase source. With verified English/context, the separate capitalization pass changes `this` to `This`; rendering must show that explicit uppercase source and 1.5em indentation. A missing marker/show binding or uncertain language refuses the relevant repair. Protected `iPhone`, math and non-English cases remain unchanged in source and rendering.
- `This holds.#footnote[Reason.]\n\n#paragraph_tab\nNext.` becomes a footnote line, `#parbreak()`, a blank line, marker, then `Next.`. Another fix makes no edit and neither gap rule reports it.
- Prose `This holds.#dots_space #footnote[Reason.]` ends with adjacent punctuation and footnote, not a newly introduced punctuation warning.
- Bare script wrapping preserves chained/nested script operand structure; no parser-error node is guessed. An included Markdown guide retains the exact exempt teaching sentence.
- Highlight extraction, display line splitting, and paragraph checks reach one stable final source. Light/dark cancellation/border fixtures verify the intended palette change; text/math content order remains unchanged.
- Missing/ambiguous catalog labels, namespace collisions and unknown overlay targets stay unchanged and block authoritative compilation. No fallback links, invented names or catalog writes occur.
